## 3. Редирект в WhatsApp после заявки

Сейчас после `status: 'success'` показывается экран с кнопкой. Нужно: заявка улетает в таблицу → экран «Спасибо» → через 1,5 с автоматически открывается WhatsApp с готовым сообщением. Кнопка остаётся как запасной вариант (блокировщики всплывающих окон, десктоп без WhatsApp).

### Логика (в `submit`, после `this.track('Lead')`)

```javascript
this.track('Lead');
this.setState({ status: 'success', submitId: id });
const waUrl = this.waLeadUrl(data, id);
this.setState({ waLeadUrl: waUrl });                 // кнопка «Открыть WhatsApp» ведёт сюда же
setTimeout(() => { this.track('Contact'); window.location.assign(waUrl); }, 1500);
```

`window.location.assign` в той же вкладке — не блокируется как pop-up; на телефоне открывает приложение WhatsApp, на десктопе — WhatsApp Web. Страница с экраном «Спасибо» остаётся в истории (кнопка «Назад»).

### Текст сообщения — `waLeadUrl(data, id)`

```javascript
waLeadUrl(d, id) {
  const t = this.t();
  const city = d.city === 'Астана' ? t.waCityAstana : t.waCityAlmaty;
  const msg = t.waLead
    .replace('{name}', d.name.trim())
    .replace('{id}', id || '—')
    .replace('{city}', city);
  return `https://wa.me/${this.CFG.phone}?text=${encodeURIComponent(msg)}`;
}
```
